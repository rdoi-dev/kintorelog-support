# 料金プラン案内の内容確認（2026-11-02）

## 確認対象

subscriptions.htmlを、アプリのSubscriptionPolicy / SubscriptionService / RecordingService / AppModelContainer / RecordExport仕様、ローカルStoreKit設定と照合。

- Free 15/日・180/月、Plus 50円/月で25/日・300/月、Pro 80円/月で無制限を一致させた。
- 月額の請求期間と、記録日の暦月による上限を分離。過去日・削除・プラン変更時の件数も実装と一致。
- 提供前の予定価格と明記。本番販売は無効のままなので、すでに契約できるという説明にはしない。
- 購入なしの有料移行はないことと、有料登録後の自動更新を区別。
- 解約／下位変更で直ちに権限を下げる、解約だけで返金される、といった誤解を防ぐ表現へ修正。
- 承認待ち・通信失敗を契約終了と断定しない。猶予期間はAppleが適用した場合に限定し、必ず付与されるとは約束しない。
- 購入の復元と記録の復元を区別。CSVはアプリ全体のバックアップではなく、読み込み不可。端末内保存と削除・故障のリスクを説明。
- アプリ削除では解約されないこと、App Storeの購入用Apple Accountで確認すること、サポートへ不要なカード情報・記録を送らないことを追加・維持。
- 上限到達・契約終了だけでは記録を削除しないことを明示。アプリ自体の既存の編集・削除制約まで解除するとは説明しない。

## Apple公式との照合

- https://developer.apple.com/app-store/subscriptions/ ：自動更新、上位変更／下位変更の適用、ストアの地域価格。
- https://support.apple.com/ja-jp/118428 （英語版も確認） ：設定からの解約と購入用アカウント確認。
- https://support.apple.com/ja-jp/118223 ：Appleへの返金申請。返金の可否をアプリ側で保証しない。
- https://www.apple.com/legal/internet-services/itunes/jp/terms.html ：購入・支払い・サブスクリプションの条件。

独自の法的条件や返金不可の断定は追加していない。一般向け案内としてAppleの購入／購読画面と公式案内へ接続する。

## 表示の確認

ブラウザのデスクトップ表示と375px幅で、概要・比較表の表示と折り返しを確認。ローカルリンク・ページ内アンカー、プランの数値、HTMLの構造を確認。スタイル追加は.plans-pageの中へ限定し、サポートとプライバシーページの構造は変更しない。

## 配信前に残る条件

実商品・実価格・契約期間・購読グループと階層・請求猶予の設定はApp Store Connect登録後に再照合。Sandbox実機での最終確認が済んでから、予定の表示とアプリの販売有効化を更新する。
